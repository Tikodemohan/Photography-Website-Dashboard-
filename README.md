
# 📸 Photography Website

## Project Overview

Photography Website is a simple and responsive front-end web project developed using HTML and CSS. The website is designed to present photography content through a clean layout, attractive background image, and easy-to-use navigation menu.

## Project Objective

The objective of this project is to design a visually appealing photography website while improving front-end web development skills using HTML and CSS.

## Key Features

* Responsive web design
* Sidebar navigation menu
* Clean and modern user interface
* Photography-themed background
* Simple and user-friendly layout

## Technologies Used

* HTML5
* CSS3

## Project Structure

* `index.html` – Main webpage
* `style.css` – Website styling
* `photo.jpg` – Background image

## Learning Outcomes

* Developed a responsive webpage using HTML and CSS.
* Improved understanding of webpage layout and styling.
* Learned how to organize project files and publish projects on GitHub.

## Conclusion

This project demonstrates the fundamentals of front-end web development by creating a simple and responsive photography website. It serves as a beginner-friendly project for practicing HTML and CSS concepts.
